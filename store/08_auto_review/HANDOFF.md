## Checked and fine
- **Safety return paths:** rejected → no story. All kept drafts fail safety → fallback, and the fallback's story is returned only if it passes safety, otherwise the canned message. Survivors have no hard failures. `best_available` drops safety failures and is only reached when at least one draft passes safety. The single-draft `select` is reached only when that draft passed safety. No path returns an unsafe story.
- **Money:** one `OpenRouterClient` per `run()`. `baseline` makes 1 call. Retries are bounded (`RETRIES`). 4xx other than 429 are not retried. `BudgetExceeded` is not swallowed by the retry loop. `temperature` is never sent. Reasoning is off, usage is included, and `require_parameters` is set.
- **Spec rules:** feedback is hard-first. Keep-better gives a both-order disagreement to prev. Selection is survivors only, a tie gives no win, then soft failures, then index. `MAX_ROUNDS` caps revisions (`range(1, MAX_ROUNDS+1)`) with an early stop on all-pass. Depth iff premise. The unknown category gives the fixed set cozy/adventure/silly. comfort without a worry becomes cozy. Brainstorm count and categories are enforced in code. Skipped dimensions are dropped in code no matter what the judge says (but see #1). The judge's user message is only the story, and judge.md/compare.md never mention revisions.
- **Secrets:** no key in code or traces. `grep sk-or` hits only docs/store text. `.env` is ignored (`.gitignore:2`). `.env.example` holds an empty key.
- **Async:** drafts run concurrently via `gather`, and the two compare orders and the selection pairs are gathered too. Trace mutation is single-threaded asyncio with distinct `draft_N` timing keys and sorted `drafts`, so there is no race.
